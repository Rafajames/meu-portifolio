// sobre mim

Do suporte ao código

Trabalho com suporte técnico atendendo pessoas, equipamentos, redes e sistemas. Foi no campo, resolvendo os mesmos problemas várias vezes, que comecei a programar.

Minha rotina é diagnosticar, consertar e configurar. Com o tempo percebi que boa parte das dificuldades se repete: encontrar uma sala em um prédio grande, registrar um atendimento, revisar a qualidade do que foi feito. Em vez de aceitar o retrabalho, passei a criar ferramentas para resolver isso, para mim e para os colegas.

Comecei com Java e hoje desenvolvo principalmente para a web. Gosto de aprender na prática, testar soluções e entregar algo que as pessoas usem de verdade.

  • Simples para quem usa

    Faço sistemas para quem não é da área técnica. Se precisa de manual, ainda não está pronto.

  • Funciona em qualquer lugar

    Celular, computador, com ou sem internet. No campo nem sempre tem sinal.

  • Nasce de um problema real

    Cada projeto começa numa dor do trabalho e melhora com o retorno de quem usa.
